# deltalabs. — publiczne obrazy relacji

Repozytorium zawiera wyłącznie zatwierdzone obrazy JPG przygotowane do publikacji w relacjach Instagram `@deltalabs.pl`. Obrazy są publiczne, aby oficjalne API Meta mogło je pobrać. Źródła redakcyjne, tokeny i dane prywatne pozostają poza repozytorium.

Każda edycja ma osobny katalog `story-RRRR-MM-DD/` z pięcioma obrazami `story-01.jpg`–`story-05.jpg`.
Przed wysłaniem relacji agent sprawdza, czy publiczne pliki są identyczne z zatwierdzonymi obrazami.
